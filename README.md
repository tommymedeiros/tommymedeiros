# Tommy Medeiros

Product Design Engineer · Quebec City, Canada

I design and build interfaces, with design systems at the centre of my work. Trained in graphic design, I work across design and frontend development to turn design intent into usable interfaces and reusable components.

My experience spans government platforms, financial services, and industrial applications. I bring that experience to complex, data-intensive interfaces where accessibility, consistency, and maintainability matter.

In my independent practice, I build applications from design system to deployment. I also develop AI agent workflows and Model Context Protocol (MCP) integrations, using code review and automated checks to evaluate their output.

## Tools and practices

My frontend work uses React, TypeScript, HTML, CSS, and Tailwind CSS. I connect Figma Variables with DTCG design tokens and use Vitest, Playwright, Git, and CI/CD in my development workflows.
